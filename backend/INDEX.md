# Backend Index

- `main.py` API entrypoint and route wiring
- `config.py` environment settings and constants
- `models.py` request, response, and domain models
- `prompts.py` AI prompt templates
- `vector_store.py` ChromaDB integration
- `rag.py` chunking, embedding, storage, and retrieval
- `feedback_parser.py` raw parsers for TXT, CSV, PDF, and manual text
- `feedback_service.py` ingestion orchestration
- `analysis_service.py` product insights generation
- `customer_service.py` customer report generation
- `analysis.py` fallback analysis helpers
- `examples.py` sample Python client usage
- `API_TESTING.md` curl-based API checks
- `RAG_ARCHITECTURE.md` retrieval pipeline explanation
- `DEVELOPER_GUIDE.md` implementation notes
- `MANIFEST.md` backend deliverables checklist
