# Manifest

This backend starter includes:

- FastAPI application with required routes
- Pydantic models for feedback, uploads, analysis, and reports
- OpenAI embedding and analysis integration points
- ChromaDB persistent vector store wrapper
- RAG chunking and retrieval pipeline
- TXT, CSV, PDF, and manual feedback parsing
- Developer and API documentation
- Example environment variables and dependency list

This scaffold is intended to be readable first, then extensible.
